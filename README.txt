VPa06 — Генератор краткой версии «Недели рынка БГ»

Быстрый запуск на Windows
1. Распакуйте архив целиком. Не запускайте файлы внутри ZIP.
2. Откройте папку и дважды нажмите START_WINDOWS.cmd.
3. При первом запуске потребуется интернет: устанавливаются Jinja2, Playwright и Chromium.
4. Готовый PDF появится в output и откроется в системной программе.
   Если автоматическое открытие не сработало, откройте PDF вручную.
Требуется установленный Python 3.12 с командой py. Cursor не нужен.

Ручной запуск в PowerShell из папки проекта:
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe .\pdf_generator.py

Следующие запуски после установки:
.\.venv\Scripts\python.exe .\pdf_generator.py

Что изменить для нового выпуска
- data/news.csv: одна строка на блок, кодировка UTF-8, разделитель — запятая.
  Столбцы: id, category, title, event, meaning, action, source_name, source_url, source_page.
  Для текста с запятыми нужны кавычки: удобнее редактировать таблицу и сохранять CSV UTF-8.
- data/issue.json: период, вступление, «Мой взгляд», контакты, статус, полный URL выпуска.
- templates/weekly.html: оформление HTML/CSS и плейсхолдеры Jinja2.
- Имя нового PDF задаётся через --output output/имя.pdf.

Собираются ВСЕ строки CSV в ОДИН документ. В примере пять блоков: три информационных
и два практических пояснения. Это не пять независимо подтверждённых новостей.
Шаблон рассчитан на две страницы с текущей длиной текстов; при увеличении объёма
число страниц может вырасти. Проверяйте результат после каждого выпуска.

Источники и редакционный статус
Данные адаптированы из предоставленного BG_WEEKLY_2026_09 27.pdf, период внутри
документа: 21–28 сентября 2026. Факты и ссылки повторно не проверены.
Комментарий «Мой взгляд» — предложенный текст для утверждения Виталием.
Ссылка на полный выпуск не придумана: поле full_url оставлено пустым.
Обложка использована как ориентир цвета, отдельный титульный лист не добавлен.
Генератор не собирает новости, не отправляет сообщения и не публикует файлы.
Перед публикацией проверьте источники, формулировки, контакты и статус.

Соответствие заданию
Есть CSV из пяти строк, HTML-шаблон, Python CLI, сохранение в output,
автоматическое открытие PDF, PROMPT.txt и OFFER.txt.
Вместо WeasyPrint применяется Chromium через Playwright. Проект создан в ChatGPT,
Cursor не использовался. Эти отличия от учебного примера явно указаны.

Сдача на GitHub
Загрузите pdf_generator.py, requirements.txt, START_WINDOWS.cmd, README.txt,
PROMPT.txt, OFFER.txt, data/ и templates/. Пример PDF можно положить отдельно.
Не загружайте .venv и установленные браузеры. Ссылка на репозиторий ещё не создана.
В комментарий вставьте оффер и укажите адаптацию задания и использованные инструменты.

Проверка
Локальная генерация и визуальная проверка выполняются в среде ChatGPT.
Запуск на вашем Windows и автоматическое открытие нужно подтвердить отдельно.
